# Dual-endpoint audit

This offline addendum separates two questions for ten route stacks already used in the manuscript:

1. Did the response expose one exact action from the four registered actions?
2. Did the response satisfy the complete six-field output contract and expose the correct action?

The action-only parser accepts a parser-owned object or one strict top-level JSON object. It rejects
code fences, prose recovery, duplicate keys, non-standard JSON constants, type coercion, and action
normalization. The full-contract endpoint uses each frozen run's existing syntax, schema, and
cross-field semantic verdict. Every scheduled item and pair stays in both end-to-end denominators.

The generated aggregate contains counts, confusion matrices, route-stack labels, and source
digests. It contains no raw response, error text, provider response identifier, or credential. This
audit changes no frozen record and makes zero model calls.

Rebuild from the repository root:

```text
python scripts/build_dual_endpoint_audit.py --check
```
