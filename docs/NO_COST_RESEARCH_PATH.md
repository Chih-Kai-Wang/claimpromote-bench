# No-cost research path

When additional model access is unavailable, project progress is measured through benchmark
validity rather than model count:

1. audit metadata and shallow-structure shortcuts;
2. replace synthetic evidence with bounded executable fixtures;
3. accept independently executed, hash-bound model runs through the contribution contract;
4. improve controlled-pair diversity, blind review, and hidden-test discipline;
5. report single-model pilots as pilots and keep cross-model generalization open.

This repository now implements the first three infrastructure layers. It still does not claim
an executed model study, external reproduction, or a frozen hidden test.
