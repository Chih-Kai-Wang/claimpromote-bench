Weekly capacity is assumed to be 8–12 hours. The project does not expand v1 into live web
research, cross-science tasks, RL, fine-tuning, or large-model training. Independent external
benchmark review remains welcome as optional supplementary validation, but it is not a
repository-defined publication requirement. If no external audit is obtained, the report must
state that limitation explicitly and must not claim independent agreement or reproduction.

Success is not measured by stars, downloads, clone traffic, model self-ratings, or a gate
catch presented as model improvement.
